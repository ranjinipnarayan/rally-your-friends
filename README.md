# Rally

Rally helps friends make plans without the back-and-forth. Create a plan, share a
link, and collect everyone’s replies in one place.

[Try Rally](https://rally-your-friends.com)

## What it does

- Pick a time or run a poll to find one that works for everyone.
- Choose a location, search for places, or collect suggestions from friends.
- Share an invitation link so friends can respond without creating an account.
- Confirm the plan and download a calendar event.
- Sign in by email to save and revisit your rallies.
- Manage drafts, responses, final plans, and past rallies from your account.
- Share links with personalized preview images.

## Hosting

The frontend and server routes run on **Cloudflare Pages**. **Supabase** provides
the database, authentication, and personalized share-image generation.
